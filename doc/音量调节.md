# 五格波形与 SW2 音量调节（2026-10-22）

## 使用方法

SW2 拨到 ON 后，短按并松开 KEY2 增大音量，短按并松开 KEY4 减小音量。每次变化 5%，共 0%～100% 的 21 档，到端点保持。短按需超过约 50 ms 的消抖时间、短于约 1 秒；长按不连调，也不会触发上一张或轮播。

复位／上电默认 75%，与原来的 192/256 增益一致。关掉 SW2、切换图片或用 SW3 切换琶音／PCM 后，音量保持；断电或 KEY1 复位后恢复默认，不写入 TF 卡。

屏幕顶部中央常显 `VOL  75%`，音量模式为黄色，其他时候为白色。0% 表示静音，100% 表示保留原音频样本幅度。静音不会暂停 PCM、改变播放速度或字幕进度。显示器自身的音量仍单独生效，这里的百分比不是声压分贝。

SW2 的按键优先级高于缩放和缩略图预览：开启时 KEY2／KEY4 只调音量，不放大缩小、不移动焦点、不切图、不切换轮播。自动轮播暂停，退出后按原设置重新计时恢复；已发出的图片切换事务仍会完成。KEY3 保留原有预览功能。若按住 KEY2／KEY4 时拨动 SW2，该次未完成手势取消，两键均松开后再重新按。

## 波形变化

最高从四格增加到五格。底边、32 列时间历史、从右向左滚动及上升／回落平滑保持原样。包络达到 768／2304／6144／12288 时，分别显示 2／3／4／5 格；静音保留一格底条。新增一格只表现更大声音，不降低前四格门槛。

波形采集的是调音量后实际送入 HDMI 的音频，所以减小音量也会让新进入右侧的柱条变低；旧历史按原速度移出。

## 实现与引脚

- SW2 使用 C7、LVCMOS33、上拉，ON 为低电平。引脚已核对板卡 `6_cnt10.adc` 的 `SW[1]`，并登记到工程 `pin.adc`。
- `sd_card_bmp_fat32.v` 复用现有两级同步和约 50 ms 消抖；`volume_key_control` 处理短按、上下限和按键所有权。音量控制由顶层 `VOLUME_CONTROL_ENABLE=1` 开启。
- 音量和模式装入原有 96 位 OSD 握手邮箱的空闲位：[48:44] 为档位，[49] 为音量模式，[50] 为有效标记。不对多位档位直接逐位同步；收到首包前采用 75%。
- `media_hdmi_audio_bridge.v` 在音源选择之后统一乘增益。0～20 档映射为最接近的 `档位 × 256 / 20`，最高增益 256/256；乘法按有符号 26 位计算，正负满幅不溢出。每个 48 kHz 样本最多改变 1/256 增益，整个 0%～100% 范围渐变不超过约 5.34 ms，用于减轻音量突变杂音。普通一步约 0.27 ms。
- 桥的 `DYNAMIC_VOLUME` 默认关闭，以兼容历史调用；生产顶层开启。原 `AUDIO_VOLUME` 参数只作为桥的复位增益，运行档位默认仍为 75%。
- `volume_status_osd` 放在已登记的 `osd_overlay_24.v` 中，字符占顶部 `x=288～351、y=8～14`，避开左侧状态、缩放提示及右侧时间。帧边界锁存数字与颜色，组合叠加不增加视频流水线延迟；不新增字体 RAM。
