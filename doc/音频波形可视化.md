# 音频波形可视化

依据《第11课 音频波形可视化》说明及配套 `promax_audio_waveform.v`，在当前逐图 PCM、琶音、字幕及缩略图工程中加入时域波形和峰值条。

## 屏幕效果与操作

- 正常显示图片后自动显示，PCM 和琶音都支持，不新增按键。普通模式短按 KEY3 仍切换 PCM／琶音。
- 绿色波形位于 `(64,368)` 开始的 `512×64` 区域，中心线在 `y=400`。声音越强，波形偏离中线越远；声音越弱，波形越接近中线。
- 右侧 `x=584～591` 为橙色峰值条，声音越强，条越高。
- 波形位于现有字幕背景区域 `y=438～461` 上方，两者不重叠。只有波形线、中心线和峰值条替换图片像素，其余像素保留完整 RGB888。
- 四格缩略图预览期间隐藏波形，仍持续采样，返回单图后显示近期音频。缩放模式中的单图仍显示波形。
- PCM 缺失、换音等待或缓冲欠载时，实际 HDMI 输出为零，下一次完整波形更新后回到中线、峰值条归零。不会展示没有被播放的旧 PCM 或后台预读的音频。

这里的“音量”指 FPGA 输出样本的幅度。文件内声音强弱和顶层 `AUDIO_VOLUME` 增益都会影响图形；显示器自身的音量按钮不会把音量值传回 FPGA，因此不会改变波形高度。没有自动把小声音放大到满屏，强弱关系保持真实。

## 与例程的对应关系

保留 32 个采样点、默认 `DECIMATE=12`、双缓冲及 VS 下降沿换帧。48 kHz 下每点间隔 0.25 ms，32 点窗口约 8 ms（首尾跨度 7.75 ms），约每个视频帧更新一次。讲义中“约半秒”的换算不正确；本实现采用例程参数，未按半秒调整采样。

每个样本横向显示 16 像素，纵向线宽 3 像素，遵循例程的阶梯状时域显示方式；不是 FFT 频谱。全幅信号的纵向偏移限制为中心上下 31 像素，避免负满幅越出显示区。默认增益为 192/256，正常峰值通常低于满幅。

为适应现有工程作了以下处理：

1. 从 `media_hdmi_audio_bridge` 的 `audio_valid` 和 `audio_left_data[23:8]` 取样。这是音源选择、静音处理和音量增益之后，实际送到 HDMI 的 16 位有符号样本。采集和显示均使用 25 MHz 像素时钟，不增加跨时钟数据通路，也不改变 PCM 读取或 48 kHz 节拍。
2. 两个 32×8 位采样缓冲共用一个同步 RAM。只在采满 32 点且到达帧边界时切换，显示侧不会读取正在写的 bank。未采满时在帧边界隐藏旧曲线并清零峰值，避免停流后残留旧音量。
3. 峰值使用整个视频帧内所有有效音频样本的 16 位绝对值，不只检测被抽取的 32 点，避免漏掉短促鼓点。`-32768` 正确转换为无符号幅度 32768；每帧清除当前采集峰值，弱音或静音不会继承旧峰值。
4. 同步 RAM 读取和像素叠加分为两拍，RGB、VS、DE、坐标与帧起始一起延迟。随后进入字幕原有两拍流水线，最终交给 AXIS；有效区仍为每行 640 像素、每帧 480 行。
5. 顶层 `AUDIO_WAVEFORM_ENABLE=1` 默认开启，可在重新构建时设为 0 隐藏。模块默认位置保留例程的 `y=400`，实际顶层覆盖为 `y=368` 以避开字幕。
