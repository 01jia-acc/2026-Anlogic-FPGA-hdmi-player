# AUDIO3 文物讲解

以下盘符、生成文件和卡内校验描述来自队友电脑的历史记录，不代表当前本机 TF 卡已经写入。本次合并只纳入讲解文本与说明，没有复制 PCM 或 WAV、没有修改本机 TF 卡。

`AUDIO3_后母戊鼎.txt` 为中文讲解稿，主题是后母戊鼎。使用 Windows 自带的 Microsoft Huihui Desktop 普通话合成语音，语速设置为 -1。

2026-10-21 已生成并写入 TF 卡根目录 `G:\AUDIO3.PCM`：

- 48000 Hz、16 位有符号小端、单声道，原始 PCM，无 WAV 文件头。
- 时长约 113.989 秒，长度 10942968 字节。
- 从符合上述参数的 WAV 使用 `doc/convert/wav_to_pcm.py` 转换，已回读卡内文件确认与 WAV 样本逐字节一致，无满幅削波样本。
- SHA256：`45499436795fa66da064c43bc38b09952739e336bd248fa31e49f6fb5f11ed00`。

本机试听 WAV 保存在 `tests/build/AUDIO3_后母戊鼎.wav`，属于本地生成文件，不纳入 Git。卡内 `PIC3.BMP` 的实际画面未据此修改，讲解为独立制作的文物示例。

安全弹出 TF 卡后插回开发板，按 KEY1 重新扫描，普通模式短按 KEY3 切到 PCM，并切换至 `PIC3.BMP`；对应讲解将循环播放。更换音频文件无需重新生成位流；柱条门槛修改则需要重新构建并下载位流才会生效。本次未运行布局布线。
