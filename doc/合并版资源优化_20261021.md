# 合并版资源优化（2026-10-21）

## 输入证据

合并位流构建报错 MSlice=5271，设备上限 4900，超出 371。
本机 `src/td_project/lab_ex5_i2s_v1.0_Runs/syn_1/lab_ex5_i2s_v1.0_gate.area` 显示 LUT=16788、寄存器=10917、BRAM9K=54/64。层次统计中：

- `u_frame_loader`：LUT=2285、ripple=61、seq=206、BRAM=0。
- `u_volume_scanner`：LUT=1240、ripple=223、seq=2944、BRAM=0。

这说明写入 FIFO 在旧构建中没有映射到 BRAM；不能简单将全部逻辑压力归因于音频运算。

## 修改

1. `media_frame_loader.v`：把 512 深度写入 FIFO 的数据读写从带异步复位的控制块中分离为独立同步 RAM 端口，添加与工程其它 RAM 相同的 BRAM 推断属性。存储宽度从 32 缩到实际 RGB 的 24 位，SDRAM 输出处补回固定零字节。读口和 `app_wr_en` 同拍更新，控制器继续在下一拍接收原位置数据，不额外增加出队延迟。保留 FIFO 计数、突发、背压、垂直翻转和错误处理；复位只清有效状态，不复位 RAM 内容。
2. `fat32_volume_scanner.v`：增加紧凑音频表参数；实际板级实例启用后，将 16×(32 位首簇+32 位长度) 的 1024 位寄存器及宽选择器替换为 16×64 位同步 RAM。单个写地址与完整目录项一起锁存，只有一个写端口。有效掩码在复位／重扫时清零，未匹配项不使用 RAM 旧内容。保留默认并行接口供旧 scanner 独立测试／兼容实例使用，板级实际实例不连接并行表。
3. `sd_fat32_image_source.v`：查到物理音频槽后增加一个周期读取同步 RAM，再进行长度校验与启动；快速切图仍由最新显示提交覆盖旧换音请求。

不减少图片／音频数量，不关闭字幕、缩略图、缩放、转场，不改媒体格式和 UART 格式。RAM 消耗会增加，确切块数与 MSlice 减少量必须以 TD 重新综合报告为准。

## 缩略图全屏预览跑飞修复

板上出现水平错位和重复条纹时，原因是 50 MHz SDRAM 下缩略图平均每个 VGA 输出像素需要两个源像素，已经没有余量承受普通读突发之间的 12 个空闲周期。RTL 中缩略图路径现在将突发间隔设为 0，普通整图路径不变；测试台同时改为连续 VGA 像素消费，640×480 缩略图仍通过且无欠载。重新上板时应重点确认四格预览连续显示完整，若仍有条纹再提供新的 `reader_error`/欠载诊断值和时序报告。

### 再次跑飞后的修正

上板反馈表明，仅取消突发间隔不足以解决问题；上述带宽分析属于原因假设，不能当作已验证的硬件根因。进一步检查发现，旧路径仍读取每个源行全部 640 个字，且开始输出时该行仍在返回，半屏切换会复用同一行 RAM。因此同时存在吞吐余量不足及跨半屏返回数据覆盖的风险。

本次缩略图改为只发出源行 0、4、8、…、636 共 160 个字的读请求，返回数据连续存入行 RAM 的 0…159；每个半屏等待这 160 个字全部返回后再输出，跨半屏前不留旧 bank 的行数据在途。输出采样索引按 1 递增，画面坐标及四 bank 描述符不变。四图完整预览每帧源读取从 307200 字减少到 76800 字，不增加行缓存。普通整图和四档缩放保留原读取方式。

两套回归 `run_audio_video_merge_tests.ps1`、`run_playlist_diagnostic_tests.ps1` 全部通过，包括 50 MHz 内存时钟、640×480 连续有效像素、刷新／写仲裁停顿、完整／稀疏／空缩略图、地址和 RGB 逐点比对、音频和播放列表。仿真使用有序定延迟返回模型；实际 SDRAM 控制器为加密 IP，尚未验证间隔地址访问的内部实现。未运行 TD，资源、时序及最终硬件现象仍需重新综合并上板确认。

### 上板稳定后的清晰度升级

用户确认上述采样读取版不再跑飞，但希望四格更大、更清晰。默认改为每格 320×240、整屏 2×2 布局，直接从标准帧按横纵步进 2 采样，每格像素数由 19200 增至 76800。保留单行 RAM 和全部返回后再切半屏的保护，不增加完整帧缓存或插值乘法器。相对已稳定的小预览版，四图源读取量从每帧 76800 增到 307200 字，读取带宽增加，不能据此声称新尺寸已通过实板验证。

OSD 同步扩展边框／编号位置，标题叠加在顶部，帮助信息移到底部。`THUMBNAIL_DIV=2` 为新版，reader 与 OSD 同时设为 4 可恢复旧居中布局。两套回归再次全部通过，音视频回归增加旧布局兼容验证；新版与旧版均在 50 MHz、640×480、连续有效像素及仲裁停顿下逐点检查通过。未运行 TD、未生成位流、未推送，实际 MSlice／BRAM／时序与新尺寸稳定性需重新构建后确认。
