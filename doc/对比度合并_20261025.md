# 开场动画与对比度分支合并

本地开场动画、字库与资源精简先保存为 c6d8a0c，并推送到远程备份分支 `backup/opening-before-contrast-20261025`。随后合入队友提交 2603758（SW1 对比度及四键画面调节），目标分支为 `codex/next-image-prefetch`。

## 审阅与处理

- 保留本地 PIC1 一次性开场、开场期间普通 OSD／波形隐藏、图4 SRT 样本同步字幕和十槽配置。
- 保留 `.COMPACT_LOG(1)`，避免把精简串口恢复为完整诊断逻辑。
- SW1 ON：KEY1／KEY2 对比度加／减，KEY3／KEY4 亮度加／减；SW1 OFF 时 KEY1 恢复复位。SW1 优先于音量调节，退出调节不误触切图或预览。
- 解决顶层 RGB 选择冲突：开场使用无普通 OSD 的图片路径，普通模式串接新的对比度提示，波形仍在开场期间禁用。
- 修复队友实现的组合问题：原顺序为亮度／淡出后做以 128 为中心的对比度，低对比度会把黑场抬成灰色。现改为原图对比度及饱和截断后再做亮度／淡出，任意对比度下黑色端点正确。不新增视频流水级，保留默认参数逐像素等于原图。
