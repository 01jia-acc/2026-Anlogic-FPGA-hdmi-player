# 音频柱条审核与合并

本地基线先保存为 `6e4ad3d`，再合并远端 `origin/codex/audio-waveform-scroll` 的 `d4e624c`。本次未推送远端。

审核确认该分支新增音量包络与 32 列滚动历史显示，不改变 SD 音频读取和逐图配音规则。采集实际 HDMI 增益处理后的样本，静音也参与记录；缩略图中隐藏显示并继续采样。柱条与字幕各延迟两拍 RGB、VS、DE 和坐标，视频出口共延迟四拍。同步 RAM 的读取与像素流水线对齐，默认固定 16 像素列间距，不引入运行时除法器。

合并保留本地十槽扫描、音频元数据表、十张循环、居中四格布局、缩略图稀疏读取与行返回保护。恢复 TD 工程绝对路径为本机 D 盘，保留新增波形源文件登记。队友旧分支中的 16 槽支持没有恢复。本次未提高缩略图像素或改动缓存带宽策略。

修正此前未通过的 `tb_image_pcm`：十槽夹具原先按 1、5、9、10、8、7 提交逻辑图片，但实际扫描结果按文件编号升序排列。统一为 1、5、7、8、9、10；分别保留缺配音、空文件、奇数字节文件和有效循环音轨检查。目录仍含 11～16 号音频以检查其不进入有效表，缺号配音仍按文件编号而非播放序号匹配。

本机验证全部通过：

- `tests/run_audio_video_merge_tests.ps1`：4518 个逐图 PCM 样本、音源切换、FAT、四 bank、双线性缩放、Wipe、50 MHz 下 640×480 缩放及两种缩略图布局的逐像素／逐地址检查。
- `tests/run_playlist_diagnostic_tests.ps1`：十槽扫描、循环、稀疏文件、串口快照及四图窗口交互。
- `tests/run_waveform_modelsim_tests.ps1`：音量包络、环形回绕、静音尾迹、真实 HDMI 增益、三帧 640×480 柱条／字幕／AXIS、UTF-8 字幕与像素对齐。

新增 ModelSim 脚本使用本机 E 盘安装，保留原有 Icarus 脚本供队友使用。队友 AUDIO3 文本一并保留，未写入本机 TF 卡。

未运行 TD 综合、布局布线或生成位流。32×8 历史表带强制 RAM 属性，可能增加一块 BRAM，实际资源与时序需检查本版 TD 报告；不能引用旧分支历史资源作为当前合并版的结论。
