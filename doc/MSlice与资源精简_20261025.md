这些是修改前报告，不代表新代码的资源数，也不是MSlice数。ripple为算术进位链相关资源，在该报告总量中与lut列一起计入LUT用量。

1. 顶层启用 `uart_debug_logger.COMPACT_LOG=1`。日志从230字节缩为47字节：

   `P=1 I=1 T=0 B=0 D=1 E=00 V=1 M=03FF U=0A J=01`

   P/I：时钟及SD初始化；T：状态；B/D：扫描忙/完成；E：错误；V：有效显示；M：图片存在掩码；U：图片数量（十六进制）；J：当前加载序号。J并非始终等于屏幕图片，后台预读时可能是下一张。

   不再输出的簇号、扇区、CRC、文件长度、PCM内部快照、播放列表快照等，其采样寄存器和UART字符选择逻辑不再被引用，综合器可以裁掉；仅服务于这些输出的上游逻辑也可随之消除。功能控制使用的状态仍然保留。UART接收字幕不受影响。将顶层COMPACT_LOG改回0可恢复完整诊断输出。

2. 日志周期计数器从固定32位改为按周期计算的 `$clog2` 位宽，50MHz、1000ms对应26位。

3. 开场布局取消动态 `top/left/length` 组合后再进行宽位加减和边界比较的通用矩形算法。固定行直接比较y的位段，普通文字只算固定x偏移，标题滑动单独用6位位置、8位相对坐标。上位检查防止坐标截断后在屏幕右侧产生重复文字。

4. 保留原有字体ROM、两拍字幕流水线、HDMI同步信号、音频采样链路和跨时钟功能握手，不通过删除同步寄存器换资源。

开场仍约8秒、每次复位只播一次，文字、色彩、排布和阶段时刻保持一致。

## MSlice 是什么

MSlice是TD报告的物理逻辑资源单元，用来容纳组合逻辑LUT、触发器及相关选择、进位结构。它不是内存容量、CPU运行时间，也不是Verilog代码行数。

EG4S20资源表给出19600 LUT、19600 FF，而本工程TD给出4900 MSlice上限。可以用19600/4900=4理解LUT容量分组的数量级，但不能把设计使用的LUT数直接除以4就当成实际MSlice数。LUT类型、寄存器搭配、时钟/复位/使能兼容性、进位链和打包规则都会影响占用；布局布线后的结果还受物理优化影响。

LUT与REG统计是不同维度。未用的寄存器槽位不能直接变成任意额外LUT，也不能直接当成BRAM或DSP。LUT占用86%但MSlice超限是可能发生的。

## Verilog例子

### 寄存器：位宽对应硬件数量

```verilog
reg [31:0] count;
always @(posedge clk) count <= count + 1'b1;
```

如果32位都有效，该电路通常需要32个触发器和相应的递增逻辑。只计0到479时用9位就够，缩小位宽还会缩小比较器和加法器。最终节省的MSlice数取决于打包，不能按每4个触发器必定省1个MSlice计算。

### always组合块里的reg不一定是触发器

```verilog
reg [7:0] result;
always @* begin
    if(select) result=a;
    else       result=b;
end
```

这是8位组合选择器，主要消耗LUT，不是8个时钟触发器。是否有时钟沿、赋值是否覆盖全部分支，以及综合是否能化简，才决定实际电路。

### 固定坐标可以简化为位判断

```verilog
// y是无符号12位坐标，这两个条件等价：
wire band_a = y >= 12'd304 && y < 12'd320;
wire band_b = y[11:4] == 8'd19;
```

常量表达式综合器往往已经能自动化简。此次主要收益在于不再先选择变量top、再计算top+height、再做比较，而是直接表达固定区域，让多余的选择和算术电路不必产生。

### 调试输出也是真电路

```verilog
reg [159:0] snapshot;
always @(posedge clk)
    if(log_start) snapshot <= internal_status;
```

若全部位都用于UART，这会保留最多160个快照触发器，再加上使能、字符选择和格式化逻辑；如果内部状态还有只为日志计算的计数器或校验，其成本也会保留。将编译时参数设为精简模式，使这些位不再被使用后，综合器才能裁掉相应电路。仅把日志发送间隔从1秒改成10秒一般不会省掉这些电路。

### 存储器和流水线的取舍

数组可以映射到BRAM，也可能因读写方式、复位写法等原因被实现为大量寄存器及选择器。同步读取通常更适合推断BRAM。BRAM保存字库后，字库容量主要计入BRAM，地址/控制/输出逻辑仍使用LUT与寄存器。

流水线增加触发器，却可以缩短组合路径，帮助达到时序。不能只看寄存器越少越好；尤其本工程RGB、DE、VS必须保持相同延迟。
